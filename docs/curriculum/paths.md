# Dual learning paths

| Path | Audience | Time | Source |
|---|---|---|---|
| **A — Conversational fluency** | Speak/design confidently | ~2–3 weeks | [curriculum.md](../curriculum.md) |
| **B — Senior implementation** | Build & operate enterprise integrations | ~8–12 weeks | This folder |

Cross-links: Path A phases offer **Go deeper → Module**; Path B modules offer **Fluency refresh → Phase**.

Progress is tracked separately in the web app — switching paths never deletes the other path’s checkmarks.

## Interactive web app

The [web app](../../web/) is the interactive runtime:

- Mermaid diagrams and section micro-checks
- XP, ranks, streaks, badges, and sequential unlocks
- Spaced revisit on drills; scored decision labs

Markdown in this folder is the readable companion (GitHub-rendered Mermaid). Runtime source of truth for Path B modules remains `web/src/content/implementation/`.
