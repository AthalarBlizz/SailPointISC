# Path B — Senior Implementation Curriculum

Enterprise ISC engineering across REST, SDKs, CLI, transforms, rules, workflows, connectors, and customizers.

**Companion to Path A:** [Conversational fluency](../curriculum.md). Swap anytime in the [web app](../../web/).

**Currency:** July 2026 per-service APIs (`/accounts/v1`), SDK 2.x method suffixes, legacy yearly EOL **Q1 2029**.

**Estimated time:** 8–12 weeks part-time.
