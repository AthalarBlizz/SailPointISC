Cold open. Module four is REST in any language — the integration-spec skill. The wrong deliverable wastes weeks. Handing ServiceNow the Python S D K forces their team to host a runtime they do not own. Giving yourself only a Postman collection skips retries, pagination, and typed clients you will need when the one-shot becomes a product.

Outcomes for this module. You can write method, U R L, headers, body, expected status, and a verify GET for a multi-step flow. You can choose a REST integration-spec when the caller is I T D R, SIEM, ServiceNow, or a webhook — not a long-running S D K app you own. And you can handle token reuse, pagination, and four twenty-nine in language-agnostic terms.

Teach — the decision rule. If the script runs on its own in a runtime you own, prefer the official S D K two point x — it handles auth refresh, retries, pagination helpers, and experimental headers. If another system must call Identity Security Cloud — I S C — give a REST call sheet plus Personal Access Token — P A T — guidance. One-shot Postman is fine to explore; graduate to S D K when it becomes yours to operate.

Teach — what a call sheet must contain. Base U R L, auth steps, and scope list. Every step: H T T P method, path pinned as slash service slash v N, headers, sample body, expected success status codes. Explicit name-to-I D resolution steps. An error matrix covering four oh one, four oh three, four oh four, four twenty-nine, and business four hundreds. Owner team and P A T naming convention.

Teach — emergency disable skeleton in words. Post to the OAuth token endpoint with client credentials. Get identities with a filter alias equals the target, using slash identities slash v one. List lifecycle states on the identity profile and pick the name Terminated. Post set-lifecycle-state on that identity with the resolved lifecycle state I D. Get the identity again to verify after state. Document that provisioning may still be asynchronous after I S C accepts the call.

Teach — production craft on the wire. Reuse one bearer token per run. Paginate with documented limit and offset or search-after patterns. On four twenty-nine, back off with jitter. Pin slash identities slash v one style paths — never hand off slash v two zero two six or slash latest as “current.” State idempotency expectations: what happens if the same disable is posted twice.

Example — say this to a ServiceNow team. You should not import the Python sailpoint package. Here is a REST call sheet: method, path, headers, body, status, name resolution, and verify GET. Here are the scopes on a dedicated P A T. Success means verified lifecycle state, not merely a two oh two accepted.

Example — say this in architecture review. Script-on-its-own goes S D K. Other-system-calls-I S C goes REST integration-spec. If security asks for a contract-first review, the call sheet is the artifact — not a private repo of S D K samples they cannot run inside their platform.

Failure modes. Giving ServiceNow the Python S D K as the integration contract. Omitting the verify GET and assuming mutation is done. Hardcoding a lifecycle state UUID in the call sheet. Using yearly or slash latest paths in a handoff labeled current. Skipping the error matrix so on-call cannot distinguish auth failure from authorization failure.

Failure modes, continued. No owner or rotation date on the P A T. Call sheets that list happy path only. Treating async provisioning as synchronous completion. Shipping a Postman collection with sandbox I Ds still embedded.

Screen close. Module four: choose the deliverable by who runs the code. REST call sheets for external platforms; S D K for automations you operate. Pin per-service paths, resolve names, verify with GET. Next is filters, Search, PATCH, and bulk — how you query and update at scale.
