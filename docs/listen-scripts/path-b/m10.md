What stays constant across TypeScript, Python, Go, and PowerShell: Personal Access Token auth, name-to-I D resolution, per-service version pins like slash identities slash v one, and operation or method version suffixes. Yearly collections are the thing you leave behind.

PowerShell’s home is Windows admin runbooks, Entra — Microsoft Entra I D, formerly Azure A D — and Active Directory ops bridges, and shops where PowerShell skill already outweighs Python packaging. Go’s home is platform services, compiled workers, and high-concurrency command-line tools. Do not force Go when the org’s I S C muscle is Python.
